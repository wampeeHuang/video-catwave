# video-catwave · YouTube → B站搬运管线

> 完整搬运管线——下载、断句、翻译、双语字幕压制、封面生成、B站元数据。一条命令完成全流程。

YouTube 视频搬运到 B站的全流程自动化。从 `yt-dlp` 下载到 B站投稿——每个环节是独立的可替换模块。

## 快速开始

```
> 帮我安装这个 skill：https://github.com/wampeeHuang/video-catwave
```

## 设计哲学

### 每个环节是可替换的模块
下载、断句、翻译、字幕压制、封面生成——用管道连接而不是耦合在一起。换一个字幕工具不影响翻译模块，换一个翻译引擎不影响压制模块。模块边界的清晰度 = 系统的可维护性。

### GPU 加速是默认，不是可选项
NVENC 编码、Whisper 语音识别——视频处理天然走 GPU。CPU 做视频处理不是"慢一点"，是"今天出不来"。

### B站元数据 = 标题 + 标签 + 封面
搬运不是"丢上去就行"。B站标题 ≤80 字、标签研究过搜索量、封面符合点击率标准——元数据质量决定视频生死，比画质重要。

## 诚实边界

- **YouTube → B站 单向。** 不做其他平台搬运
- **依赖 yt-dlp 和 YouTube 的反爬策略。** 下载可能被阻断
- **翻译质量 = 机器翻译天花板。** 双语字幕是辅助理解，不是专业翻译
- **RTX 5060 Ti 16GB VRAM。** GPU 任务受限于显存
