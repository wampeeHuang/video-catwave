时间轴宪法（不可违背）

1. 剥离 YouTube 字幕② 下载的 01_raw.srt 仅作参考存档。禁止将 YouTube 字幕用于时间轴。YouTube 自动字幕有 +2.3s 系统滞后（已通过 whisper_compare.py 实测验证），用它做锚点 = 字幕永远漂移。
2. Whisper 为唯一锚点③ Whisper 转录的 02_seg.srt 是下游唯一输入。所有翻译、拆分、ASS、渲染均以 Whisper 时间戳为准。
3. 双源保留01_raw.srt（YouTube 原始）+ 01_whisper.*（Whisper 原始）均作为过程文件永久保留。改名不移，覆盖不删。下游只消费 02_seg.srt。
4. 视频无内嵌字幕source.mp4 不含任何 subtitle track（已通过 ffprobe 验证）。如有内嵌字幕轨，② 下载时必须剥离。
5. ④ 为时间锚点赞助检测 + 视频裁切在 stage ④ 完成，切完立即用 _shift_timestamps() 修正所有下游字幕时间戳。此后时间轴不再变化。

2.3 判定 Go/No-Go

3.4.5 已知问题与恢复流程

封面上传不可靠。文件可设置到 editor 内的 file input，但 Vue bcc-upload 组件不处理 CDP 触发的 change event。编辑器内无预览图，点「完成」后封面回到 B站默认占位图。恢复：在 Bit Browser 中手动拖入封面 → 点「完成」。
上传完成后页面自动跳转。B站在上传完成后会导航到 /platform/home，表单填写状态丢失。页面会显示「本地浏览器存在1个未提交的视频」。恢复：点击「继续编辑」恢复草稿 → 重新运行 --no-upload 填写表单。
CDP 连接可能中断。页面导航后 WebSocket 可能变为无响应（0 events）。恢复：重新获取 PAGE_ID（curl http://127.0.0.1:55054/json），用新 ID 重连。
自定义标签无法通过 CDP 添加。只能点击推荐标签。脚本未覆盖的标签需手动输入。恢复：在 Bit Browser 中逐个输入自定义标签。
